# Bangkok Flood Data Analytics 🌧️

## Project Overview
This project explores flooding events in Bangkok, Thailand,
using environmental data analytics and visualization.

The study investigates spatial and temporal flood patterns,
flood characteristics, and relationships between rainfall,
flood depth, and flood duration.

## Research Objectives
1. Explore temporal patterns of flooding events.
2. Identify districts frequently affected by flooding.
3. Investigate relationships between rainfall and flood characteristics.
4. Visualize flood patterns using interactive dashboards.
5. Explore the potential application of machine learning
   for flood-related prediction.

## Dataset
- Location: Bangkok, Thailand
- Period: 2024–2025
- Records: 841 flood event records
- Districts: 43
- Format: Excel

## Methodology
1. Data Collection
2. Data Cleaning and Transformation
3. Exploratory Data Analysis (EDA)
4. Data Analysis and Insights Extraction
5. Data Visualization
6. Basic Machine Learning (Optional)
